# A-tatis 2.0

Mascota virtual 2.5D para Android protagonizada por una capibara unicornio.

## Mecánicas

- Cinco habitaciones con perspectiva y profundidad simulada.
- A-tatis camina al tocar el piso, salta, duerme, come, se limpia y reacciona a abrazos.
- Baño interactivo: jabón, cepillo, toalla y burbujas animadas mediante arrastre.
- Tienda de comida e inventario. La comida debe arrastrarse hasta la boca.
- Personalización con seis estilos y seis colores.
- Cuatro minijuegos: Tetris simple, patineta, bola saltarina y avión mágico.
- Moneda de estrellas ganada en minijuegos y guardado local.
- Sin anuncios, cuentas, internet ni permisos sensibles.
